# SoloDesk — MVP prototype

## Run locally
1. Extract this folder.
2. Open `index.html` in a modern browser.
3. Add a client, then create an order.

No build tools or server are required for this prototype.

## Included
- Dashboard and recent orders
- Client directory
- Create/edit/delete orders
- Order status and deadline tracking
- Revision allowance and revision count
- Partial payment recording
- Earnings overview
- Search and status filters
- JSON export/import
- Local browser persistence

## Important limitations
- Data is stored only in the current browser/device using localStorage.
- No login, cloud sync, multi-device backup, encryption, or server-side storage.
- Do not enter sensitive client information.
- Export JSON backups regularly.
- Payment records are manually entered; the app does not process payments.
- Currency totals are kept separate; different currencies are not converted.

This is an early prototype for user testing, not a production-ready SaaS.
